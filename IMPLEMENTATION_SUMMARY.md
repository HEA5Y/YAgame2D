### 2. ✅ Разделён bootstrap() на этапы
```javascript
async bootstrap() {
    await this._initSDK();        // Этап 1: SDK
    await this._createManagers(); // Этап 2: Registry
    await this._loadResources();  // Этап 3: Ассеты
    this._registerEvents();       // Этап 4: События
    await this._loadSave();       // Этап 5: Сохранения
    this._processOffline();       // Этап 6: Оффлайн
    this._startGame();            // Этап 7: Запуск
}
```
